# Tool Loan API

API REST desarrollada con FastAPI para la gestión de préstamos de herramientas.

## Tecnologías

- Python 3.13
- FastAPI
- SQLAlchemy
- PostgreSQL
- Docker
- Docker Compose
- Alembic
- Pydantic

## Estado del proyecto

🚧 En desarrollo.

## Cómo ejecutar

```bash
docker compose up --build
```
